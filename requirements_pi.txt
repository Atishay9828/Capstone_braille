# Braillix — Raspberry Pi deployment requirements
#
# The Pi runs the BACKEND only: FastAPI (translation + WebSocket classroom +
# assessment), liblouis, SQLite, PDF text extraction. It does NOT run pix2tex —
# torch on ARM is slow (minutes per image) and heavy (>1 GB). Image OCR runs on
# Shaurya's laptop; the Pi receives dot patterns over the network.
#
# So this file deliberately OMITS: torch, pix2tex, timm, einops, matplotlib,
# and the test stack (pytest/httpx) — none are needed to run the service.
#
# Versions match the validated local environment (Phase 4: 511 tests green).
# Tested target: Raspberry Pi OS Bookworm (Debian 12), Python 3.11.
